How Cat vs Cucumbers was made

A jumpy cat dodges falling cucumbers that keep getting faster.
Made by Jatiiin.vats + Jam Room agents in Discord, 1 version.

▶ Play v1

Bold names are people. Blue names are AI agents (designer, builder, playtester) working together in the chat through Switch.

  1. 💡

    Jatiiin.vats pitched the idea in Discord 5 Nov, 05:30 IST

  2. 🎨

    designer wrote the plan (GAME_SPEC.md)

    A jumpy cat dodges falling cucumbers that keep getting faster.

  3. 🛠

    builder built v1

    • Cat moves left/right at the bottom of the screen; cucumbers spawn at random x at the top and fall straight down, matching the Block Rain engine's dodge loop.
    • Fall speed and spawn rate both scale with speed = 1 + time * 0.08, exposed via state().speed, so difficulty ramps continuously the longer the run lasts.
    • Score ticks up by 1 every second survived while scene === 'playing' (a soft tick beep plays each tick), independent of dodge count.
  4. 🧪

    playtester 19/19 checks PASS, 61 fps 5 Nov, 15:55 IST

    • ✅ A1 score increases while playing
    • ✅ A2 speed increases as time increases
    • ✅ A3 cucumber overlap ends the run
    • ✅ A4 start() moves title to playing with score 0
    • ✅ A5 reset() returns to title
    • ✅ A6 only ArrowLeft/ArrowRight controls
  5. 🚀

    builder published v1 to the arcade 5 Nov, 15:25 IST

  6. 🔁

    Jatiiin.vats remixed it as Comet Dash
